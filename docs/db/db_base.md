# DbBase — 外部仕様書

## 概要

`yklibpy.db.db_base.DbBase`

辞書ベースのストレージ実装が共有する基底クラス。
`DbYaml` などの具体的なストレージクラスが継承する。

## コンストラクタ

```python
DbBase()
```

空の連想配列 `assoc: dict[str, object]` を内部状態として初期化する。

## インスタンス変数

| 変数名 | 型 | 説明 |
|--------|----|------|
| `assoc` | `dict[str, object]` | サブクラスが利用する内部データストア |

## 制約

- メソッドを持たない抽象的な基底クラスであり、単独でインスタンス化しても意味を持たない。
- サブクラスは `assoc` を自由に利用してよい。

## 依存関係

なし
