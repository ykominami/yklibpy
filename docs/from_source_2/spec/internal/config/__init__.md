# config — 内部仕様書

**ファイル**: `src/yklibpy/config/__init__.py`

## 概要

`AppConfig` をパッケージ直下へ再公開し、ログによる疎通確認関数を提供します。

## モジュールレベル定数・型

| 変数名 | 値/型 | 用途 |
|--------|-------|------|
| `__all__` | `["AppConfig", "xmain", "ymain"]` | パッケージの公開 API を定義します。 |

## モジュールレベル関数

### `xmain() -> None`

config パッケージの標準疎通確認メッセージをデバッグログへ記録します。

### `ymain() -> None`

別系統の疎通確認メッセージをデバッグログへ記録します。

## 依存

| クラス/変数 | 用途 |
|-------------|------|
| `AppConfig` | パッケージ直下から再公開します。 |
| `Loggerx` | 疎通確認ログを記録します。 |
