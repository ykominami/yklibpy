# Env — 内部仕様書

**ファイル**: `src/yklibpy/common/env.py`  
**継承**: なし

## 概要

YAML 設定から基準パスとパターン別設定を読み込み、処理対象ファイル群を解決します。

## インスタンス変数

| 変数名 | 型 | 説明 |
|--------|----|------|
| `sequence` | `int` | 対象ディレクトリ名から得る処理順です。未決定時は `-1` です。 |
| `base_path` | `Path` | ファイル探索の基準パスです。 |
| `pattern` | `str | None` | 選択中の設定パターン名です。 |
| `config` | `dict[str, Any]` | 選択中の設定ブロックです。 |
| `assoc` | `dict[str, Any]` | YAML 全体の設定です。 |

## メソッド

### `__init__(config_path: Path | None = None) -> None`

既定値を初期化し、設定パスがあれば YAML を読み込んで `base_path` を組み立てます。

### `make_path(path_array: list[str]) -> Path`

先頭要素を取り出し、残りの要素を連結したパスを返します。

**設計上の副作用**: 引数のリストを `pop(0)` で変更します。

### `mode() -> str`

選択中設定の `mode` を返し、未指定時は `H3` を返します。

### `set_base_path(base_path: Path) -> None`

探索基準パスを置き換えます。

### `set_pattern(pattern: str) -> dict[str, Any] | None`

パターン名を保持し、対応する設定ブロックがあれば選択して返します。

### `get_files() -> list[Path]`

選択中設定から対象ファイル一覧を解決します。

処理フロー:

1. 設定が空なら `sequence` を `-1` にして空配列を返します。
2. `dir` の各要素を基準パスへ連結し、末尾名を整数化して `sequence` に設定します。
3. `kind` が `file` なら列挙されたファイルパスを返します。
4. それ以外はディレクトリ直下のファイルを収集し、ソートして返します。

**Raises**: `KeyError` — 必須設定キーがない場合。  
**Raises**: `ValueError` — ディレクトリ名を整数へ変換できない場合。

## 依存

| クラス/変数 | 用途 |
|-------------|------|
| `yaml.FullLoader` | YAML 設定を読み込みます。 |
| `Loggerx` | ファイル解決過程をログ出力します。 |

## 設計上の注意

YAML の構造を実行時に直接仮定しており、スキーマ検証はありません。通常の進行状況も `error` レベルで記録されます。
