# SafeDict — 内部仕様書

**ファイル**: `src/yklibpy/common/safedict.py`  
**継承**: `dict[str, str]`

## 概要

文字列テンプレート展開時に、未定義キーを例外にせず元のプレースホルダー形式で残す辞書です。

---

## メソッド

### `__missing__(key: str) -> str`

存在しないキーを `{key}` 形式へ変換して返します。

**Args**: `key` — 辞書に存在しなかったキーです。  
**Returns**: 未解決プレースホルダー文字列です。

## 設計上の注意

値とキーを文字列に限定した型付けであり、一般用途の辞書代替ではありません。
