# DbBase — 内部仕様書

**ファイル**: `src/yklibpy/db/db_base.py`  
**継承**: なし

## 概要

辞書ベースのストレージ実装が共有する最小の基底状態を提供する。

---

## インスタンス変数

| 変数名 | 型 | 説明 |
|--------|----|------|
| `assoc` | `dict[str, object]` | 汎用の連想配列。 |

## メソッド

### `__init__() -> None`

`assoc` を空辞書で初期化する。

## 設計上の注意

抽象メソッドやプロトコルは定義せず、派生クラスへ状態だけを提供する。`DbYaml` は独自の `data` を使用するため、現状 `assoc` は活用されていない。
