# cli.__init__ — 内部仕様書

**ファイル**: `src/yklibpy/cli/__init__.py`

## 概要

CLI 基盤の公開 API を再エクスポートし、疎通確認用エントリポイントを提供する。

---

## モジュールレベル定数・型

| 変数名 | 値/型 | 用途 |
|--------|-------|------|
| `__all__` | `list[str]` | `Cli`、`xmain`、`ymain` を公開する。 |

---

## モジュールレベル関数

### `xmain() -> None`

既定の挨拶をデバッグログと標準出力へ出力する。

### `ymain() -> None`

別系統の挨拶をデバッグログと標準出力へ出力する。

---

## 依存

| クラス/変数 | 用途 |
|-------------|------|
| `Cli` | 公開 API として再エクスポートする。 |
| `Loggerx` | 疎通確認メッセージを記録する。 |

## 設計上の注意

直接実行時は `xmain()` を起動する。`__all__` に関数を含めることで、実装クラスと CLI エントリポイントを同じ名前空間から提供している。
