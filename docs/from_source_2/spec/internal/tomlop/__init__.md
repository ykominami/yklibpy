# tomlop.__init__ — 内部仕様書

**ファイル**: `src/yklibpy/tomlop/__init__.py`

## 概要

TOML/YAML 操作のクラスと CLI エントリポイントをパッケージ API として公開し、疎通確認関数を提供する。

---

## モジュールレベル定数・型

| 変数名 | 値/型 | 用途 |
|--------|-------|------|
| `__all__` | `list[str]` | `Tomlop`、`FileItem`、変換関数、疎通関数を公開する。 |

## モジュールレベル関数

### `xmain() -> None`

疎通確認メッセージを標準出力とログへ出す。

### `ymain() -> None`

別系統の疎通確認メッセージをログへ出す。

---

## 依存

| クラス/変数 | 用途 |
|-------------|------|
| `Tomlop` / `FileItem` | 公開クラス。 |
| `zmain` / `toml2yaml` / `yaml2toml` | 公開 CLI 関数。 |
| `Loggerx` | 疎通確認ログ。 |

## 設計上の注意

直接実行時は `xmain()` を呼ぶ。`ymain()` は標準出力を行わず、`xmain()` と挙動が非対称である。
